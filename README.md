# Hotel Booking Application

## Description
The Hotel Booking Application is a web-based platform that allows users to search, book, and manage hotel reservations. It provides a simple interface to streamline the hotel booking process.

## Features
- Search hotels by location and dates
- View available rooms and pricing
- Book hotel rooms
- Manage existing reservations

## Tech Stack
- **Frontend:** JavaScript, HTML, CSS
- **Backend:** Java

## Getting Started

### Prerequisites
- Java (JDK) installed
- A modern web browser

### Clone the repository
```bash
git clone https://github.com/velu-murugesan/hotel-booking-application.git
cd hotel-booking-application
```

### Run the backend
1. Open a terminal and go to the backend folder (if applicable).
2. Run your Java backend (update the command below to match your build tool):

```bash
# Example (replace with Maven/Gradle command or your jar)
java -jar path/to/backend.jar
```

### Run the frontend
- Open the frontend entry file (for example `index.html`) in your browser, or serve it using a simple server.
